The Models

Sarnoff's Law (V ∝ n): The value of a broadcast network (like traditional TV or Radio) is proportional to the number of viewers. Adding one more viewer adds exactly one "unit" of value.

Odlyzko's Law (V ∝ n log n): A more conservative model for communications networks, suggesting that while value grows faster than linearly, the "utility" of each connection diminishes as the network becomes massive.

Metcalfe's Law (V ∝ n²): The value of a telecommunications network is proportional to the square of the number of connected users. Each new participant adds a potential connection for every existing member.

Reed's Law (V ∝ 2ⁿ): The value of "Large-Scale Group-Forming Networks" (social networks, DAOs, communities). The value scales with the number of possible *subgroups*, which grows exponentially.

Why This Matters

Network effects explain why the internet tends toward concentration — the value curve rewards scale nonlinearly. But they also explain why protocols can be more powerful than platforms. A protocol (email, HTTP, Bitcoin) can't be owned, which means its network effects benefit everyone rather than accruing to a single company.
